# Local override policy

Remote themes are most useful when local overrides are rare and deliberate. The plugin allows overriding theme files by placing a file with the same path in the local site, so an override policy is needed to prevent every site from drifting away from the shared system.

## Our policy:

Prefer configuration and data before overrides.

Allow content overrides freely.

Allow CSS overrides only in a dedicated local override file.

Avoid overriding layout files unless a site has a real structural need.

Track all overrides here, in this file, docs/override-guide.md.
